# Kern's Spookbox

Paranormal field instrument web app.

## Features
- Spirit box sweep + Witch Board
- **Spiritual Warfare** — multi-tradition rite library
- **EVP** — mic record, mark, playback, session log
- **SLS** — camera stick-figure scan
- **Cold Spot** — sensor meter with honest fallback
